# Snow Running

Рождественская пиксельная аркада о Санте, который собирает подарки в больших лабиринтах и управляет ледяными стенами, чтобы задержать монстров.

## Запуск

Требуется Node.js 20 или новее.

```powershell
npm install
npm run dev
```

Откройте адрес, напечатанный Vite в терминале. Статическую сборку можно получить командой `npm run build`; папка `dist` готова для публикации как HTML5-игра.

## Управление

- Игрок 1: стрелки для движения, Space — создать или разбить лёд перед Сантой.
- Игрок 2: WASD для движения, E — действие Снегурочки.
- P — пауза, Esc — меню.

Соберите все подарки на уровне, чтобы открыть выход. У команды три общие жизни. Колокольчик даёт очки и может вернуть одну жизнь. Когда жизни закончатся, забег завершится; костюм и лучший локальный счёт сохраняются.

## Режимы и содержимое прототипа

В меню можно начать одиночный забег или играть вдвоём на одном компьютере. В текущей сборке есть три больших образца уровней: Пряничный городок, Лес северных оленей и Мастерская Санты. Кампания рассчитана на расширение до 33 уровней. На первом этапе уровни постепенно знакомят с подарками и выходом, ледяным действием, а затем с разными схемами поведения монстров.

В меню можно переключить костюм Санты и Деда Мороза. Снегурочка становится вторым персонажем в кооперативе, а Куки-пряник помогает объяснить правила.

## Онлайн-рекорды

Без настроек игра полностью доступна офлайн, а результат сохраняется локально. Чтобы включить общую таблицу:

1. Создайте проект Supabase и примените `supabase/migrations/001_leaderboard.sql`.
2. Разверните функцию `submit-score` из `supabase/functions/submit-score`.
3. Настройте секрет `SUPABASE_SERVICE_ROLE_KEY` только в Supabase Function Secrets.
4. Скопируйте `.env.example` в `.env.local` и укажите URL проекта и публичный anon key.
5. Перезапустите Vite и соберите игру.

Публичный ключ используется только для чтения таблицы и вызова функции. Сервисный ключ остаётся на серверной стороне и не добавляется в браузерную сборку.

## Принципы уровня и вдохновение

- Каждый вид монстра имеет простое, различимое поведение: патруль, погоня или попытка выйти наперерез.
- Первые уровни знакомят с целями без перегрузки, затем совмещают знакомые правила с новым поведением врагов.
- Ледяная стена меняет маршруты и даёт временную передышку, но не убирает опасность из уровня.
